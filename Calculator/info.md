# 🧮 Calculator

A simple **Java console calculator** that allows you to perform basic arithmetic operations using user input.

The program displays a menu, lets you choose an operation, takes two numbers, and then calculates the result. 💻

## 🎮 How to Use

When you start the program, you'll see:

```text
Welcome to Calculator

Choose one operation:
1. Add
2. Subtract
3. Exit
```

Choose an option and enter two numbers.

### ➕ Addition

```text
Select the operation: 1

Number 1 is: 25
Number 2 is: 15

The sum is: 40
```

### ➖ Subtraction

```text
Select the operation: 2

Number 1 is: 25
Number 2 is: 15

The difference is: 10
```

### 🚪 Exit

Choose `3` to exit the calculator:

```text
Select the operation: 3

Exiting the calculator, bye bye! 👋
```
